Use this glossary to learn about terms used in Router Pay. 

## Acknowledgment

## ISA (Instruction Specific Address)

An address that is unique to a particular instruction.

## PDA (Program Derived Address)

An address that is unique to a particular program.  

## Vaults

A storage unit for assets.

## Operator Nodes

Nodes that are used to run the Router Pay chain.
